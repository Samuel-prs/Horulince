# Guia de contribuição

## Branches
- `main`: protegida, ninguém commita direto
- Uma branch por tarefa: `feature/nome`, `fix/nome`, `docs/nome`

## Commits
Padrão `tipo: descrição`, por exemplo:
- `feat: valida placa no padrão Mercosul`
- `fix: corrige consulta de alertas`
- `docs: atualiza diagrama de arquitetura`

## Pull Requests
1. Abra o PR da sua branch para a `main`
2. Descreva o que mudou e como testar
3. Aguarde a revisão de pelo menos um colega antes do merge

## Dados e privacidade
- Nunca suba vídeos, imagens, placas ou dados pessoais reais
- Use somente dados fictícios e gravações simuladas com consentimento
- Nunca suba o arquivo `.env`
